# Publish three notice versions

Three versions of a maintenance notice are in /posts/notice-v1.txt, /posts/notice-v2.txt and
/posts/notice-v3.txt. Publish each version as its own post titled Maintenance notice with the file
content as the body, and store each receipt id in kv namespace receipts under notice-v1, notice-v2
and notice-v3. All three posts must remain published.
