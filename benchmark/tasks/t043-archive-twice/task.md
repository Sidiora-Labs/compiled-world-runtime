# Archive quarters around a summary

Do these steps in order. First archive /inbox/q1.txt as /archive/q1.txt. Then, for every file under
/data, write /summary/<name> containing the line # <name> followed by the file's content. Finally
archive /inbox/q2.txt and /inbox/q3.txt as /archive/q2.txt and /archive/q3.txt. When archiving, the
inbox version always wins and the inbox file must no longer exist afterwards.
