# Cancel two job sets around a publication

Do these steps in order. First cancel whichever of the jobs w1, w2 and w3 have not finished. Then,
for every file under /minutes, write a copy with the same name under /minutes-public whose first
line is PUBLIC followed by the original content. Finally cancel whichever of the jobs z1, z2, z3 and
z4 have not finished. A job that has finished must keep its result.
