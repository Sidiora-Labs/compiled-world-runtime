# Build a search catalogue

For every topic in /topics.txt (one per line), search for it with a limit of three results and write
the result titles, one per line, to /catalogue/<topic>.md, where <topic> is the topic with spaces
replaced by hyphens. Then write /catalogue/README.md with one line <topic>: <number of titles
written> per topic, in the order of /topics.txt.
