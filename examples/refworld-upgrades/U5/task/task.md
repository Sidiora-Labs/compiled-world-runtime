kv holds three receipts under the keys receipt-golf, receipt-tennis and receipt-chess. Write each one
to the file /receipts/<key>.txt with the stored value as its content; for example the value of
receipt-golf goes to /receipts/receipt-golf.txt. Leave the kv entries in place.

In your first turn, write receipt-golf only.
From your second turn on, write receipt-tennis and receipt-chess.
